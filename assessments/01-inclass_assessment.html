ECON 525: Data Management & Visualization in Economics

In-class Assessment #1: Exploring the command line

About

The goal of this activity is to practice the Bash commands covered in class, including navigation, file management, text processing, redirection, pipes, loops, and scripting.

Assessment policy: The use of AI tools and all external sources is strictly prohibited. Only materials and content covered in class are permitted.

Instructions

1. Open Bash and locate the course folder

  • Open the cloned Econ525-Fall2026 repository in VS Code.
  • Open a Bash terminal. On Windows, select Git Bash. On macOS, open Terminal and type bash.
  • Move to the repository's 03-shell folder. In VS Code, you may right-click 03-shell and select Open in Integrated Terminal.
  • Run pwd to confirm that your working directory ends in Econ525-Fall2026/03-shell.
  • Confirm that the terminal profile is Bash. Your prompt may look different from the examples shown in class.

2. Use the help available in Bash

  • Run ls --help | less, mkdir --help | less, and rm --help | less. Press q to leave less.
  • Because cd is a Bash built-in command, use help cd.
  • Git Bash normally does not include man, so you do not need it for this assessment.

3. Create the assessment directory

  • From 03-shell, list the available files with ls -lh.
  • Create a directory named econ525_assessment.
  • Copy examples/nursery.txt into the new directory and rename the copy sample.txt. Use only Bash commands.
  • Move into econ525_assessment and confirm the location with pwd.
  • Create my_script.sh and edit it with nano.

4. Write the Bash script

Your my_script.sh file must complete the following tasks in this order:

  1. Begin with the shebang #!/usr/bin/env bash.
  2. Print Hello, Data Science! to the terminal.
  3. Use cat to display all of sample.txt.
  4. Use head to display the first 7 lines of sample.txt.
  5. Use tail to display the last 7 lines of sample.txt.
  6. Redirect the output of ls -lh to directory_list.txt.
  7. Use a pipe to sort directory_list.txt and display the sorted result with less.
  8. Create a directory named texts.
  9. Use a for loop to create texts/file1.txt through texts/file5.txt. Each file should contain its corresponding message, such as This is file 1.
  10. Concatenate the five files into texts/all_texts.txt. Do not include all_texts.txt as one of its own inputs.

Save the script with LF line endings. In nano, press Ctrl+X, then Y, and then Enter to save and exit.

5. Run and check the script

  • Run the script with bash my_script.sh. Executable permission is not required when you invoke the script this way.
  • Use ls -lh and ls -lh texts to confirm that the script created the required files.
  • Use cat texts/all_texts.txt to confirm that the final file contains five messages in order.

Submission

  1. Compress the complete econ525_assessment directory using File Explorer on Windows or Finder on macOS. Name the archive FirstName_LastName_econ525_assessment.zip.
  2. Submit the .zip file through the corresponding Canvas assignment.
  3. Upload a screenshot of your terminal that shows the script command and its output.

The assessment will be graded based on completion of the requested tasks and the correctness of the Bash commands, script, and generated files. Replace FirstName and LastName with your own first and last names.
